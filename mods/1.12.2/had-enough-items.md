# Had Enough Items (HEI)

A Just Enough Items (JEI) fork for Minecraft 1.12.2 focused on stability, performance, and usability. The project describes memory, loading, and rendering optimizations, recipe and ingredient bookmarks, bookmark groups, and autocrafting.

- Target: Minecraft 1.12.2 / Forge
- Category: interface and recipes
- Installation side: client required; server optional, according to Modrinth metadata
- Distribution: [Modrinth](<https://modrinth.com/mod/had-enough-items>)
- Development: [CleanroomMC/HadEnoughItems](<https://github.com/CleanroomMC/HadEnoughItems>)

## Installation notes

The project describes HEI as a non-coremod with no dependencies other than Forge. Treat it as a JEI replacement rather than an additional independent recipe browser; check the selected release and the compatibility of existing JEI integrations when migrating a pack.

Autocrafting must be enabled in the configuration. Feature availability and controls may vary by release; consult the project documentation for the build you install. No performance improvement is guaranteed for a particular pack.
