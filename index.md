## Minecraft 1.7.10

- [Angelica](<mods/1.7.10/angelica.md>) - A renderer designed to improve rendering in 1.7.10.
- [ArchaicFix](<mods/1.7.10/archaicfix.md>) - Aims to reduce memory usage, stuttering, and other issues.
- [BugTorch](<mods/1.7.10/bugtorch.md>) - A collection of patches for Minecraft bugs.
- [ChunkAPI](<mods/1.7.10/chunkapi.md>) - An API for working with custom chunk data.
- [CoreTweaks](<mods/1.7.10/coretweaks.md>) - Provides startup improvements, crash fixes, and other tweaks.
- [EndlessIDs](<mods/1.7.10/endlessids.md>) - Extends ID limits for blocks and other content.
- [GTNHLib](<mods/1.7.10/gtnhlib.md>) - A shared library used by GTNH-related mods and others.
- [Hodgepodge](<mods/1.7.10/hodgepodge.md>) - Collects fixes for Minecraft and various mods.
- [InventoryBogoSorter](<mods/1.7.10/inventory-bogo-sorter.md>) - Helps organize and sort inventories.
- [JarJar](<mods/1.7.10/jarjar.md>) - A Jar-in-Jar plugin for RetroFuturaBootstrap.
- [lwjgl3ify](<mods/1.7.10/lwjgl3ify.md>) - Enables newer Java versions and LWJGL 3 on 1.7.10.
- [ModularUI2](<mods/1.7.10/modularui2.md>) - A library for building mod GUIs.
- [NotEnoughItems Unofficial](<mods/1.7.10/nei-unofficial.md>) - A GTNH-maintained fork of NEI for browsing items and recipes.
- [UniMixins](<mods/1.7.10/unimixins.md>) - Combines bootstraps for mods that use Mixin.

## Minecraft 1.12.2

- [Celeritas](<mods/1.12.2/celeritas.md>) - A renderer that improves terrain rendering in 1.12.2.
- [Chibi (formerly LoliASM)](<mods/1.12.2/chibi.md>) - An optimization mod focused on memory usage, crash prevention, and more.
- [Cleanroom](<mods/1.12.2/cleanroom.md>) - A loader and ecosystem for 1.12.2, built as a continuation of MinecraftForge.
- [Demonica](<mods/1.12.2/demonica.md>) - A shader support mod derived from Actinium, with roots in Iris.
- [Had Enough Items (HEI)](<mods/1.12.2/had-enough-items.md>) - A JEI fork with performance optimizations, enhanced recipe bookmarks, and autocrafting.
- [PaperFixes](<mods/1.12.2/paperfixes.md>) - Ports bug fixes and performance improvements from CraftBukkit / Spigot / Paper to a Forge mod.
- [Pulsar lighting engine](<mods/1.12.2/pulsar.md>) - A lighting engine for Cleanroom based on Starlight / SuperNova, with SCALAR / RGB modes.
- [Roughly Enough IDs (REID)](<mods/1.12.2/reid.md>) - Extends block, item, biome, potion, and enchantment ID limits using a newer chunk format.
- [StellarCore](<mods/1.12.2/stellarcore.md>) - A collection of client and server performance improvements and mod compatibility fixes.
- [Universal Tweaks](<mods/1.12.2/universal-tweaks.md>) - A collection of bug fixes and tweaks for 1.12.2. Each change can be toggled in the configuration.
- [VintageFix](<mods/1.12.2/vintagefix.md>) - Improves startup, resource loading, memory usage, and more.

- [Cleanroom Official Website](<resources/cleanroom-site.md>) - Official entry point for the Cleanroom loader, community mods, tools, and documentation.
