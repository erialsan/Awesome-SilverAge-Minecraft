# GTNH Forks and Development Repositories

The [GTNewHorizons GitHub organization](<https://github.com/GTNewHorizons>) hosts many mod forks and continued-development versions, alongside libraries and tooling. It is a useful starting point when looking for maintained versions of older mods.

Examples in this list include [Angelica](<../mods/1.7.10/angelica.md>), [Hodgepodge](<../mods/1.7.10/hodgepodge.md>), [NotEnoughItems Unofficial](<../mods/1.7.10/nei-unofficial.md>), and [GTNHLib](<../mods/1.7.10/gtnhlib.md>).

## Before Using a Fork

Not every repository is a fork, and not every GTNH fork is a drop-in replacement for a general-purpose modpack. Check Minecraft and Java versions, dependencies, release notes, migration requirements, and licenses. Pack-specific changes may affect behavior outside GTNH.
