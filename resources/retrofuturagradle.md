# RetroFuturaGradle

[RetroFuturaGradle](<https://github.com/GTNewHorizons/RetroFuturaGradle>) is a Gradle plugin for developing Minecraft 1.7.10 Forge mods, intended to replace the legacy ForgeGradle toolchain.

It provides a Forge-enabled development environment, dependency deobfuscation, enhanced generic type information, and fixes for legacy build and reobfuscation issues. The project documents support for Java toolchains, configuration and build caches, and task configuration avoidance.

## Usage Notes

This is build tooling, not a mod to install in a game's mods folder. Start with the repository's [example](<https://github.com/GTNewHorizons/RetroFuturaGradle/tree/HEAD/example>) and check the Gradle and Java requirements for your chosen plugin release. A build-tool migration does not by itself change the mod's Minecraft target or runtime compatibility.

The project links [GTNHGradle](<https://github.com/GTNewHorizons/GTNHGradle>) as an example of a more complex build setup; it is a separate plugin, not another name for RetroFuturaGradle.
