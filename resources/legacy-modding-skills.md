# Legacy-Modding-Skills

[Legacy-Modding-Skills](<https://github.com/erialsan/Legacy-Modding-Skills>) by erialsan provides procedures and knowledge for migrating legacy Minecraft mod build environments with AI agents. It is a development resource, not a mod to install in the game.

- **1.7.10** - Migration to GTNH's ExampleMod1.7.10 build template.
- **1.12.2** - Migration using either CleanroomModTemplate or ForgeDevEnv.
- **Shared safeguards** - Preserve behavior, check dependencies, and collect build/startup evidence.
- **Navigation** - An OKF v0.2 index with version-specific playbooks and shared knowledge.

## Usage Notes

Choose the Minecraft target and template before following a playbook. A build-template migration does not authorize upgrading Minecraft or dropping Forge compatibility. These Skills have not been installed or executed as part of preparing this list.
